Root cause: H2D input write racing compute stream in speculative decoding
Traced a deterministic NaN corruption under concurrent load to set_input() writing via cudaStreamPerThread (no implicit sync with compute stream on HIP) while the previous ubatch's graph was still reading the same input tensors. Fixed with a synchronize before set_inputs() in llama_context::process_ubatch.
